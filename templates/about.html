About the Crop Recommendation System

A simple machine learning project designed to support agricultural decision making.

1. Project Overview

Agriculture plays a vital role in food security and the economy. Choosing the right crop for specific field conditions is crucial for maximizing crop yield and preventing financial loss.

The Crop Recommendation System is a simple, student-level Machine Learning project that guides farmers and agriculture practitioners to select the most suitable crop based on their soil chemical properties and local meteorological conditions.

2. Machine Learning Approach

This system implements a Random Forest Classification algorithm.

  • Algorithm: Random Forest is an ensemble learning method that constructs a collection of decision trees during training.
  • How it works: Each decision tree votes on the most probable crop based on input thresholds, and the majority class becomes the final recommendation.
  • Why Random Forest: It offers high classification accuracy, handles multi-class agricultural data effectively, and prevents overfitting compared to a single decision tree.

3. Input Parameters Explained

The system evaluates 7 core agricultural features before arriving at a recommendation:

  • Nitrogen (N): Promotes vegetative leaf growth and green foliage.
  • Phosphorus (P): Essential for root establishment, flowering, and seed formation.
  • Potassium (K): Enhances disease resistance, drought tolerance, and fruit quality.
  • Temperature (°C): Influences photosynthesis rate and growing season length.
  • Humidity (%): Determines plant transpiration and moisture retention.
  • Soil pH: Controls the availability of essential nutrients to plant root systems.
  • Rainfall (mm): Determines natural water availability throughout the crop cycle.

4. Technology Stack

  • Frontend: Clean HTML5, Vanilla CSS3 (Agricultural Green/White Theme), JavaScript
  • Backend: Python with Flask microframework
  • Machine Learning: Scikit-Learn (Random Forest Classifier), Pandas, NumPy
  • Persistence: Pickle model serialization (crop_model.pkl)
